# Project Overview

## Overview
- Personal portfolio site for Raunav Ghosh, hosted via GitHub Pages at `imraunav.github.io`.
- Built with Jekyll using the default `minima` theme.
- Focuses on Computer Vision, Machine Learning, signal processing, and engineering experience.

## Key Goals & Philosophy
- Keep the site lightweight, readable, and fast to load.
- Maintain simple Markdown-based content without unnecessary external dependencies or build tooling.
- Preserve GitHub Pages native compatibility (no custom build pipelines required).

## Conventions
- Prefer small, clean commits and edits.
- Keep content factual, technical, and well-structured.
