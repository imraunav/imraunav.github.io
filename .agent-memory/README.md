# Agent Memory

This directory stores notes that an agent should remember while working on this repository.

Use it for:
- project facts and conventions
- useful reminders from previous changes
- decisions that are not obvious from the code alone
- short task notes that should persist across sessions

Keep entries concise and relevant.

## How to use this directory

Create a small, focused file for each topic instead of putting everything into one long note. This makes it much faster to find the relevant memory without scanning every file.

### Naming convention

Use simple, descriptive filenames such as:
- `project-overview.md` for repo-level context
- `site-structure.md` for site conventions and important files
- `content-updates.md` for notes about pages, content, or publishing work
- `debugging.md` for recurring problems or fixes
- `decisions.md` for major repo decisions and rationale

### Index

Keep this README updated with a short index of memory files and what each one contains.

| File | Purpose |

| [debugging.md](debugging.md) | Known issues, observed fixes, and troubleshooting notes |
| [decisions.md](decisions.md) | Major design decisions and rationale for future agents |

### Maintenance guidance

- Add a new file when a topic is large enough to deserve its own note.
- Update the index whenever a new memory file is created or renamed.
- Keep memory entries short and practical.
- Prefer facts, decisions, and reminders that are useful across sessions.
